THE CHAPTER'S THESIS: linear algebra is insufficient for machine intelligence, and it is
also nearly all of it. Interleave linear maps with one small fixed nonlinearity applied
coordinate by coordinate, and the stack escapes the limits of its parts while keeping their
mathematics. Nearly all the computation, and nearly all the parameters, live in the matrix.

NOTATION (2E house macros -- use these, not the literature defaults):
  Lambda = number of layers (NOT an eigenvalue matrix)
  Psi    = all parameters (weights and biases)
  L      = the loss
  varsigma = the activation function (macro \activation)
  y-hat  = network output
  delta  = the error signal / costate

CORE CONCEPTS:

1. Beyond Linear Transformations (13.1)
   - No matrix computes XOR; no composition of linear maps is more expressive than one linear map
   - Activation functions applied elementwise (Def 13.1): ReLU, sigmoid, tanh
   - Universal Approximation (Lemma 13.2): one hidden layer of sufficient width approximates
     any continuous function on a compact set
   - Universality is an existence statement about WIDTH; it says nothing about learnability,
     depth efficiency, or the number of samples required

2. Network Architecture & Matrix Factorization (13.2)
   - Feedforward network as alternating affine maps and elementwise nonlinearity (Def 13.3)
   - h_{l} = varrho(W_l h_{l-1} + b_l), with a purely LINEAR final layer
   - Read as a learned factorization: the SVD factors analytically, a network factors by training
   - Parameter counting; where the parameters actually sit
   - Depth vs. width; the tent-map depth separation as the concrete witness

3. Chains & Backpropagation (13.3)
   - The problem: compute the derivative of a scalar loss with respect to millions of parameters
   - The chain rule turns the computation into a single product of matrices
   - The error signal delta is a SENSITIVITY: the derivative of the loss with respect to a
     layer's pre-activation (Def 13.4); it is the costate of optimal control
   - Backpropagation rule (Lemma 13.5): delta at layer l comes from delta at layer l+1 by
     multiplying by W_{l+1}^T and the derivative of the activation
   - The TRANSPOSE is the whole point: forward is W, backward is W^T -- the adjoint of Week 5
   - Backpropagation complexity (Thm 13.6): the full gradient costs a constant multiple of
     one forward pass
   - Base case: at the output layer with squared loss, delta is the least squares residual
     of Chapter 6, NEGATED

4. Stochastic Gradient Descent (13.4)
   - The exact gradient is an average over millions of examples; an average is an expectation,
     and an expectation can be estimated by a sample (Week 12)
   - SGD update (Def 13.7) with learning rate eta_t
   - Mini-batch properties (Lemma 13.8): unbiased gradient estimate, variance falling like 1/B
   - Smoothness and strong convexity (Def 13.10) as the hypotheses that make anything provable
   - SGD convergence (Thm 13.11) under the schedule eta_t = 2 / (mu (t + gamma)) with
     gamma = 2L/mu, giving eta_0 = 1/L
   - Binary classification worked example (Ex 13.9)

5. Attention & Transformers (13.5)
   - Every inner product in this book was CHOSEN by a modeler; attention learns one instead
   - Query, key, value: q_i = W_Q x_i, k_i = W_K x_i, v_i = W_V x_i
   - Scores <q_i, k_j> form a learned bilinear form; scaling by sqrt(d); softmax (Week 12)
     converts scores to a density over tokens
   - Output for token i is the corresponding convex mixture of values (Def 13.12)
   - Attention properties (Thm 13.13), writing Y = V S for the output:
     (a) S is COLUMN-stochastic -- each column is a density, entrywise positive, summing to one
     (b) each column of Y lies in the CONVEX HULL of the columns of V, hence in col(V)
     (c) attention is PERMUTATION EQUIVARIANT: X -> XP sends Y -> YP
     (d) cost O(n^2 max(d_k, d_v)) time and O(n^2) memory -- the quadratic bottleneck
   - Permutation equivariance is exactly why positional information must be supplied separately
   - A prompt of n tokens is a matrix X in R^{d x n} -- one column per token

6. Representation Learning (13.6)
   - The last layer is linear, so whatever the network computed must be linearly readable
     from the final hidden vector
   - Representation at depth l (Def 13.14): the composite of the first l layers
   - A representation is good exactly when what must follow it can be linear
   - Piecewise linearity (Thm 13.15): a ReLU network is continuous and piecewise-affine; on
     each polyhedral region R it equals A_R x + c_R with A_R = W_L D_{L-1} W_{L-1} ... D_1 W_1,
     each D_l diagonal, 1 for units active on R and 0 for units inactive
   - Word embeddings (Ex 13.16): geometry carrying meaning, the payoff of Ex 5.16

7. Deep Linear Algebra (13.7)
   - A network is one affine map on each region; interrogate THAT matrix
   - Autoencoders (Ex 13.17): encoder E, decoder D, bottleneck dimension k << n
   - The encoder alone confesses little (generically surjective, trivial cokernel);
     the round trip D o E is the object of study
   - ker(D o E) is the variation discarded; im(D o E) is the learned model of where data lives
   - The linear autoencoder recovers the principal subspace -- Week 11, learned rather than computed

ESSENTIAL SKILLS (core; expected without hesitation):
- Count parameters in a stated architecture
- Evaluate a small network forward by hand
- State why depth without nonlinearity collapses to a single linear map
- Identify the shapes of W_l, h_l, b_l, and delta_l and check conformability
- Apply the backpropagation rule for one layer and identify where the TRANSPOSE enters
- Recognize the output-layer error signal as the negated least squares residual
- Compare the cost of backpropagation to finite differences
- Compute a softmax and an attention weight COLUMN; verify it sums to one
- Explain what attention learns that a fixed inner product cannot
- Identify kernel and image of a linearized autoencoder round trip and say what each means
- Explain the sense in which a linear autoencoder reproduces PCA

TYPICAL MCQ TRAPS:
- Claiming universal approximation implies a network can be TRAINED to the function
- Using W instead of W^T in the backward pass
- Reporting the error signal as the residual without the sign flip
- Confusing Lambda (layer count) with an eigenvalue matrix, or the activation with a spectral radius
- Treating attention weights as symmetric (they are not; q and k play different roles)
- Calling the attention matrix row-stochastic (in the book's convention S is column-stochastic)
- Forgetting the sqrt(d) scaling before the softmax
- Asserting a ReLU network is globally linear because it is piecewise linear
- Treating the representation as the network's OUTPUT rather than the final hidden vector
- Claiming mini-batch gradients are biased (they are unbiased; only the variance changes)
- Studying the encoder's fundamental spaces instead of the round trip's
